# Agent Instructions

## Requirements

Only read files you're instructed to read.

When editing files, don't delete the file first. Make targeted patches, otherwise the user loses the ability to undo/redo in the editor.

Never run git commands.

Stat files before editing to check if they have changed since you last read them. If they have, read them again before making any edits.
